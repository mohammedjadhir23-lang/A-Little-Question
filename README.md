# Love proposal site

A no-build, mobile-friendly static website. Open `index.html` locally to preview it.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `love-proposal`).
2. Upload the contents of this folder — `index.html`, `style.css`, `script.js`, and `crying-kitten.png` — to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then select `main` and `/ (root)`, and save.
5. After GitHub finishes publishing, share the Pages link it gives you (usually `https://YOUR-USERNAME.github.io/love-proposal/`).

To personalize it, replace `J Aashifa Banu` in `index.html` with the exact name you prefer.
